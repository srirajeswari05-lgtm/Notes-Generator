# 📚 AI College Notes Generator

An AI-powered web application that converts study materials into clear, structured notes using Google Gemini AI.

## ✨ Features

- 📄 Upload PDF, DOCX, TXT, PPTX, and XLSX files
- 🤖 Generate AI-powered study notes
- 📥 Download generated notes
- 🎨 Clean and modern student-friendly interface
- ⚡ Fast and easy to use

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- PyMuPDF
- python-docx
- python-pptx
- openpyxl
- pandas

## 📂 Supported File Formats

- PDF
- DOCX
- TXT
- PPTX
- XLSX

## 🚀 How to Run

1. Clone the repository
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Add your Gemini API key inside:

```
.streamlit/secrets.toml
```

4. Run the project:

```bash
streamlit run app.py
```
